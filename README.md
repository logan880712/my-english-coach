# My English Coach

영어를 처음 시작하는 한국인 사용자를 위한 180일 회화 연습 프로그램입니다. 설치·유료 API·회원가입 없이 정해진 수업을 듣고 말할 수 있습니다. 학습 결과를 보장하는 프로그램은 아닙니다.

## 휴대폰에서 사용하기

GitHub Pages 게시가 완료되면 아래 주소를 Chrome이나 Safari에서 엽니다.

https://logan880712.github.io/my-english-coach/

1. **오늘 공부 시작하기**를 누릅니다.
2. 듣기 버튼을 누르고 화면의 말하기 과제를 따라 합니다. 영어 입력은 필수가 아닙니다.
3. 실제로 연습한 뒤 체크하고 **연습 완료 · 다음 표현**을 누릅니다.
4. **오늘 공부는 여기서 끝!**이 나오면 쉬어도 됩니다.
5. 다음 날 같은 브라우저에서 열면 다음 수업으로 이어집니다. 중간에 쉬어도 수업이 건너뛰지 않습니다.

하루 수업을 마친 뒤 **다음 수업 더 공부하기**를 누르면 기다리지 않고 이어서 공부할 수 있습니다. 같은 날 재접속해도 다음 수업이나 진행 중인 추가 수업으로 이어집니다. 추가 수업은 진도와 완료 기록에 반영합니다. 자유 연습과 수업 미리보기도 이용할 수 있습니다. 미리보기는 진도를 바꾸지 않습니다. 과정은 달력 날짜가 아니라 **완료한 수업 순서**로 진행됩니다. 180일치 수업이므로 결석하면 달력상 완료일도 늦어집니다.

## 6개월 과정

30개 주제에 180개의 날짜별 수업을 배정했습니다. **첫 수업은 새 표현 6개, 이후 매 수업은 새 회화 표현 4개 + 복습 표현 2개**입니다. 질문과 답변 예문 총 722쌍을 마련했습니다. 같은 문장을 6일 내내 공부하는 방식 대신, 같은 주제 안에서도 매일 다른 소주제와 표현을 배우며 복습은 따로 표시합니다.

| 기간 | 학습 내용 |
| --- | --- |
| 1~30일 | 인사, 하루 일과, 취향, 가족, 못 알아들었을 때 |
| 31~60일 | 카페, 식당, 식재료, 옷, 마트 |
| 61~90일 | 길, 교통, 호텔 체크인·요청, 공항 |
| 91~120일 | 약속, 직장 도움, 회의, 취미, 지난 주말 |
| 121~150일 | 잘못된 주문, 약국, 반품, 분실물, 전화 예약 |
| 151~180일 | 여행 계획, 초대·거절, 의견, 일정 변경, 종합 대화 |

하루 공부는 약 40분입니다. 화면에 오늘 분량과 다음 수업 내용을 표시합니다.

| 공부 순서 | 권장 시간 |
| --- | --- |
| 단어·표현 10개 듣고 말하기 | 5분 |
| 새 회화 표현 듣기 | 5분 |
| 예문을 따라 말하기 | 10분 |
| 예문을 가리고 내 답 말하기 | 10분 |
| 배운 표현 2개 복습 | 5분 |
| 오늘의 상황 대화 미션 | 5분 |

첫 수업은 복습 대신 새 표현과 상황 대화를 더 연습합니다. 7·14·21일차 등 매 7개 수업마다 지난 7개 수업의 단어 5문제·문장 3문제를 확인합니다. 테스트 날에는 단어 5분, 새 표현 듣기·따라 말하기 15분, 혼자 답하기 5분, 복습 5분, 주간 테스트 10분으로 약 40분을 배정합니다. 30·60·90·120·150·180일에는 월별 소통 점검을 위해 10~15분을 추가합니다.

시간은 권장 분량이며 40분이 지나야 버튼이 열리는 방식은 아닙니다. 각 표현의 연습 항목과 단어 완료 체크, 마지막 상황 대화(테스트 날은 주간 테스트), 해당 월별 점검을 끝내면 **오늘 공부는 여기서 끝!**을 표시합니다. 더 하고 싶다면 다음 수업을 이어서 공부할 수 있습니다.

기존 완료 기록의 문장·메모·테스트 결과는 당시 과정 기준으로 유지합니다. 업데이트 전에 이미 연습을 시작한 수업은 체크와 메모를 보존하기 위해 그대로 마치고, 다음 수업부터 새 과정을 사용합니다. 아직 손대지 않은 이전 수업은 새 과정으로 전환합니다. 백업 파일에는 과정 구분도 함께 저장합니다.

소통 목표는 **익숙한 상황 10개 중 7~8개에서 필요한 말을 주고받기**입니다. 모든 영어의 70~80%를 이해한다는 뜻은 아닙니다. 가능하면 주 1~2회 사람과 15~20분 실제 대화를 해 보세요. 첫 주에는 자기소개 한 문장부터 시작해도 됩니다. 자기 점검은 자동 실력 평가·발음 인증이 아닙니다.

## 듣기·마이크·피드백

듣기는 브라우저의 영어 음성 합성을 사용합니다. 기기 음량과 영어 음성 지원에 따라 동작이 달라집니다. 음성 메모는 HTTPS, 지원 브라우저, 마이크 권한이 필요하며 브라우저 제공 음성 인식 서비스에 음성이 전송될 수 있습니다. 앱은 녹음 파일을 저장하지 않습니다. 인식되지 않는 경우 소리 내어 연습하고 체크하면 됩니다.

대화는 미리 준비한 역할 대화입니다. 자유로운 AI 대화나 입력 문장의 자동 교정은 제공하지 않습니다. 자유 연습의 피드백은 준비된 예문과 한국어 안내이고, 내 문장을 실제로 교정한 결과가 아닙니다. 약국·알레르기 등 수업의 답변은 학습 예문입니다. 실제 상황에서는 자신의 사실을 말하고 전문가의 안내를 따라야 합니다.

## 기록·백업

- 진도, 체크, 답변 메모, 어려움 표시, 전체 완료 기록과 월별 자기 점검을 브라우저의 로컬 저장 공간에 저장합니다.
- 기존 복습 노트도 유지됩니다. 기존 60개 예문 데모의 날짜 기준 진도는 새 180일 수업 완료 기록으로 바꾸지 않으며, 새 과정은 1일차부터 시작합니다.
- 다른 브라우저·기기에는 자동으로 동기화되지 않습니다. 시크릿 모드나 브라우저 데이터 삭제로 기록이 사라질 수 있습니다.
- **학습 기록 → 기록 백업하기**에서 JSON 파일을 내려받습니다. 다른 기기에서 **백업 파일 가져오기**를 누르고 그 파일을 선택하면 이어서 공부할 수 있습니다. 가져오기는 기존 진도와 복습 노트를 교체하므로 필요한 기록을 먼저 백업하세요.
- 파일에는 내가 쓴 메모가 포함됩니다. 개인적으로 보관하세요.
- 저장 실패, 깨진 기록, 다른 탭의 변경을 감지하면 경고하며 기존 기록을 임의로 덮어쓰지 않습니다.

## 내 컴퓨터에서 실행

파일을 내려받고 압축을 푼 뒤 `index.html`을 열 수 있습니다. 안정적인 저장과 실행에는 HTTP 서버를 권장합니다. Python 3가 있는 경우 프로젝트 폴더에서:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

내 컴퓨터 브라우저에서 `http://localhost:8000`으로 확인합니다. 서버 종료는 Ctrl+C입니다. 클라우드 환경에서는 `/workspace/my-english-coach`에서 같은 명령을 실행합니다. 온보딩은 localhost 미리보기 링크 대신 내부 요청과 브라우저 테스트로 검증합니다.

## 파일

- `index.html`: 첫 화면, 일일 수업, 자유 연습, 복습, 전체 학습 기록
- `style.css`: PC·휴대폰 디자인
- `course-data.js`: 30개 상황의 대화 예문과 180일 수업 계획
- `course-app.js`: 일일 진도, 역할 대화, 뜻 확인, 자기 점검, 기록·백업·복원
- `curriculum.js`: 기존 자유 연습의 60개 질문·예문
- `app.js`: 자유 연습, 예문 안내, 듣기·음성 입력, 기존 복습 노트
- `README.md`: 사용·실행 안내

빌드·외부 패키지 설치·API 키가 필요하지 않습니다. GitHub에 파일을 올리는 것과 GitHub Pages의 게시 성공은 별도입니다.

## 오늘의 단어·주간 테스트·한글 발음
- 각 수업에 회화 단어·표현 10개를 표시합니다. 영어·한국어 뜻·한글 발음·듣기가 있고, 같은 상황의 단어를 돌아가며 반복합니다. 새 단어 10개가 매일 계속 추가되는 방식이 아닙니다.
- 단어를 소리 내어 연습하고 완료 체크한 뒤 하루 수업을 마칩니다.
- 7·14·21일차 등 매 7번째 수업에서 지난 7개 수업의 단어 5문제와 문장 3문제를 풉니다. 정답 수와 틀린 표현을 확인하고 기록에 저장합니다. 테스트는 그날 약 40분 중 마지막 10분에 진행합니다. 달력상의 매주 특정 요일이 아니라 완료 수업 순서 기준입니다.
- 질문·예문·문장 선택지에 한글 발음 안내를 표시합니다. 한글 발음은 영어 소리를 완전히 재현하지 못하므로 듣기도 함께 사용하세요.
- 답변 메모와 자유 연습에는 영어 또는 한글 발음을 입력할 수 있습니다. 메모는 자동 채점하지 않습니다. 주간 테스트는 뜻을 연결하는 선택형 채점이며 실제 회화·발음 평가가 아닙니다.
- 이전 기록과 복습 노트는 유지됩니다. 이전에 이미 끝낸 수업에는 단어 완료·주간 테스트 기록을 만들어 넣지 않습니다. 업데이트 뒤 진행하는 수업부터 새 기능을 사용합니다. 기존 백업도 가져올 수 있습니다.
- `speaking-support.js`에 발음 안내, 상황별 단어와 주간 문제 구성을 담았습니다.

## 재미와 집중을 돕는 말하기 미션

오늘 수업의 **작은 미션**에서 하나를 골라 사용할 수 있습니다. 추가로 반드시 모두 해야 하는 숙제가 아니라, 오늘 표현을 다른 방식으로 반복하는 도구입니다.

- **5분 집중:** 메뉴와 주변 설명을 줄이고 현재 표현을 크게 보여 줍니다. 타이머는 멈추거나 이어서 할 수 있고, 다른 화면으로 이동하면 자동으로 일시 정지합니다. 타이머가 끝나도 수업을 완료 처리하지 않습니다.
- **듣고 따라 말하기:** 현재 답변 예문을 듣고 10초 동안 직접 말하는 과정을 3회 반복합니다. 실제로 말했음을 사용자가 확인한 뒤 미션 완료를 기록합니다. 브라우저 음성 재생이 실패하면 예문을 읽고 말하기로 대신할 수 있습니다. 창을 닫거나 화면을 벗어나면 진행 중인 음성과 말하기 시간을 멈춥니다.
- **상황 대화 미션:** 현재 상황의 준비된 상대방 발화를 듣고, 6차례 내 답변을 말하고 예문과 비교합니다. 한글 발음과 한국어 뜻을 확인할 수 있습니다. 입력·마이크·AI API는 필수가 아닙니다. 답변은 사용자가 직접 말했는지 확인하며 자동 평가하지 않습니다.
- **단어 기억 게임:** 오늘 단어·표현 10개의 뜻을 선택합니다. 틀려도 다시 선택할 수 있고, 첫 시도에 맞힌 개수를 보여 줍니다. 점수는 단어 뜻 기억 결과이고 회화 실력 점수가 아닙니다.
- **성장 스탬프:** 실제 수업 완료 기록으로 첫걸음·7일·30일·90일·180일 스탬프를 표시합니다. 쉬는 날이 있어도 받은 스탬프는 사라지지 않습니다.

미션 완료 기록은 현재 수업에 저장하고, 수업을 마치면 완료 기록과 백업 파일에 포함합니다. 미리보기 미션은 실제 기록을 바꾸지 않습니다. 미션은 체크박스나 수업 진도를 자동으로 채우지 않으며, 기존 수업과 주간·월별 점검은 그대로 사용합니다. 타이머 자체는 영구 기록하지 않습니다.

`practice-activities.js`에 미션·집중 타이머·성장 스탬프를 구현했습니다. 움직임을 줄이도록 설정한 기기에서는 장식 애니메이션을 생략합니다. 실제 휴대폰의 음성 재생 지원은 기기·브라우저 설정에 따라 다릅니다.

## 원하는 만큼 추가 학습
하루 1개 수업은 권장 분량입니다. 완료 화면의 **다음 수업 더 공부하기** 또는 첫 화면의 시작 버튼으로 여러 수업을 같은 날 공부할 수 있습니다. 수업을 자동으로 완료하지 않으며 단어 연습, 회화 체크, 주간·월별 테스트는 계속 필요합니다. 180개 수업을 모두 마치면 추가 진도 대신 자유 연습이나 수업 미리보기를 사용할 수 있습니다. 기존 완료 기록은 유지합니다.

단어는 매 수업 10개이며, 단일 단어뿐 아니라 `to go`, `I'm running late.`, `Could you help me?`처럼 회화에서 함께 쓰는 짧은 표현도 포함합니다. 30개 상황마다 12개씩 마련하고 돌아가며 10개를 연습합니다. 복습 수업에서는 이전 상황의 단어·표현도 섞습니다. 단어 게임도 10개로 진행하며, 예전에 저장한 5개 게임 결과는 5개 기준 그대로 표시합니다. 기존 주간 테스트 결과와 답변 순서도 유지하고, 새로 시작하는 주간 테스트는 늘어난 단어 목록에서 출제합니다.

`daily-course-data.js`에 매일 달라지는 540쌍의 추가 대화와 첫날용 2쌍, 새 표현·간격 복습 배정을 정의했습니다. 이전 과정은 완료 기록과 기존 테스트의 호환성을 위해 보존합니다. `node --test tests/daily-course.test.cjs`로 과정 데이터와 기존 테스트 호환성을 확인할 수 있습니다.
