# My English Coach

한국인 영어 초보자를 위한 무료 회화 연습 데모입니다. 설치나 회원가입, API 키가 필요하지 않습니다.

## 내 컴퓨터에서 보기

1. 이 저장소의 파일을 내려받고 ZIP 파일이라면 압축을 풉니다.
2. 폴더 안의 `index.html`을 더블 클릭하면 웹브라우저에서 열립니다.
3. **오늘의 영어회화 시작하기**를 누르고 주제를 선택합니다.
4. 영어 답변을 입력하고 **답변 확인**을 누릅니다.
5. 기억하고 싶은 표현은 **복습에 저장**을 누르세요. **복습하기** 메뉴에서 다시 읽거나 삭제할 수 있습니다.

복습 저장은 브라우저의 로컬 저장 공간을 사용합니다. 같은 브라우저와 같은 주소에서 확인하세요. 파일을 직접 열 때 저장 동작은 브라우저에 따라 다를 수 있습니다. 안정적으로 사용하려면 아래 서버 방식으로 실행하세요. 시크릿 모드나 브라우저 데이터 삭제 시 기록이 유지되지 않을 수 있습니다.

## 클라우드 개발 환경 실행

Python 3가 준비된 환경에서 다음을 실행합니다.

```sh
cd /workspace/my-english-coach
python3 -m http.server 8000 --bind 0.0.0.0
```

내 컴퓨터에서 Python을 사용하는 경우 이 프로젝트 폴더에서 같은 명령을 실행하고 브라우저 주소창에 `http://localhost:8000`을 입력하세요. 서버를 끝내려면 터미널에서 Ctrl+C를 누릅니다. 클라우드 온보딩에서는 웹 미리보기 링크를 제공하지 않으며 내부 HTTP 요청과 브라우저 테스트로 확인합니다.

## 파일과 기능

- `index.html`: 첫 화면, 연습 화면, 복습 화면의 구성
- `style.css`: PC와 스마트폰용 디자인
- `app.js`: 5개 주제의 질문 10개, 샘플 피드백, 질문 이동, 복습 저장·삭제
- `README.md`: 사용 및 실행 안내

실제 AI 채점은 없습니다. 입력한 문장을 보여주고, 해당 질문에 준비된 자연스러운 예문과 한국어 설명을 제공합니다. 예문은 사용자의 답변을 실제로 교정한 결과가 아닙니다. 질문별 표현 점검 안내도 자동 오류 판정이 아닙니다.

복습 기록에는 고유 ID, 주제, 질문, 내 답변, 추천 예문, 설명, 저장 시각을 담습니다. 향후 AI 교정이나 서버 저장 기능으로 확장할 수 있습니다. 외부 서비스로 답변을 전송하지 않습니다.

## 회화 연습 기능
질문 듣기, 천천히 듣기, 예문 듣기를 지원합니다. 처음에는 답변 예문을 열어 한국어 뜻을 보고 소리 내어 따라 말하세요. “따라 말했어요”는 사용자가 연습 완료를 표시하는 기능이며 발음 채점이 아닙니다. 마이크 답변은 HTTPS와 브라우저의 음성 인식 지원·마이크 권한이 필요하며, 브라우저 제공 서비스에 음성이 전송될 수 있습니다. 지원되지 않는 경우 직접 입력하거나 예문을 따라 말할 수 있습니다. 듣기는 기기의 영어 음성 지원에 따라 달라집니다.
